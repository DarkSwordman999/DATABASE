# 🔎 queries — запросы с параметрами, представления, подзапросы, функции

Аналоги команд проекта [TAXI-db](https://github.com/DarkSwordman999/TAXI-db) для базы SALES: запросы с параметрами (31–46), представления (100–102), подзапросы (110–117, 199) и функции PL/pgSQL (200–204). Запускаются командой `./help <код> [параметры]`; код, файл, параметры и описание — в [`../helper/menu.txt`](../helper/menu.txt), параметры проверяются до запуска.

[← к общему описанию проекта](../README.md)

## Папки

| Папка | Коды | Содержание |
|---|---|---|
| [`select/`](select) | 31–35 | товары категории, сотрудник и его смены, история продаж товара, продажи дороже суммы, магазины с выручкой выше суммы |
| [`update/`](update), [`insert/`](insert), [`delete/`](delete) | 40–46 | изменить цену, имя, категорию, поставщика товара; добавить товар и клиента; удалить клиента и его продажи (**изменяют данные**) |
| [`views/`](views) | 100–102 | представление `V_ПРОДАЖИ` (продажи с названиями) и технологическое `V_ПРОДАЖИ_ТЕХ` (год, квартал, месяц, декада, день недели, время года, выручка, затраты), проверка |
| [`subqueries/`](subqueries) | 110–117, 199 | отклонение от средней, рейтинг товаров, продажи дороже средней по категории (коррелированный подзапрос), статистика по категориям, топ-3 товара в магазине (LATERAL), покупки клиента дороже его средней (параметр), клиенты без мелких покупок (NOT EXISTS), лучший магазин (>= ALL), все задачи |
| [`functions/`](functions) | 200–204 | `shops_above_revenue(порог)`, `revenue_by_category_and_season()`, `display_pivot_table()` (сводная таблица магазины × категории); создание и вызов |

## Примеры

```powershell
./help 31 мебель              # товары категории
./help 32 1                   # сотрудник 1 и его смены
./help 34 2000                # продажи дороже 2000
./help 102                    # представления
./help 112                    # продажи дороже средней по своей категории
./help 115 Воронов            # покупки клиента дороже его средней
./help 201 120000             # магазины с выручкой выше порога
./help 203                    # сводная таблица
```

Запросы с коррелированным подзапросом (112, 115) берут средние из `MATERIALIZED`-CTE, поэтому выполняются за секунды и на 2 млн продаж после [ЛР2](../big_db_indexes). Функции сообщают, в каком файле они определены.
