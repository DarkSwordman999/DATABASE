# 💾 lab4 — ЛР4: резервное копирование и восстановление

ЛР4 «Резервное копирование и восстановление баз данных в PostgreSQL»: база BASE создаётся из данных [ЛР1](../DATA), копируется утилитой `pg_dump` в текстовый файл, в архив rar и в многотомный архив rar, затем восстанавливается из каждой копии. Правильность проверяется контрольными задачами варианта и сравнением результатов командой `fc`.

[← к общему описанию проекта](../README.md)

## Файлы

| Файл | Назначение |
|---|---|
| [`run_all.bat`](run_all.bat) | пп. 1–10 задания целиком для варианта 20 или 22 (протокол — [`../results/lr4_vNN_protocol.txt`](../results)) |
| [`create_base.bat`](create_base.bat) | создать базу (по умолчанию `base`) из данных ЛР1 |
| [`tasks.bat`](tasks.bat) | контрольные задачи → файлы `taskN-01` (задание 1 ЛР1 варианта), `taskN-02` (задание 2), `taskN-03` (число строк в таблицах) |
| [`dump-1.bat`](dump-1.bat), [`dump-2.bat`](dump-2.bat), [`dump-3.bat`](dump-3.bat) | `pg_dump` в текстовый файл / в rar / в многотомный rar (размер тома, по умолчанию 8k) |
| [`config.bat`](config.bat) | настройки: каталог копий (по умолчанию `lab4/work`), база, путь к `Rar.exe` |

Каталог `lab4/work` создаётся при запуске и в git не хранится. При нехватке места на диске C: его можно переопределить: `$env:LR4_WORK='D:/LR4_WORK'; ./help lr4 all 20`.

## Запуск

```powershell
./help lr4 all 20              # пп. 1-10 для варианта 20;   ./help lr4 all 22 D:/LR4_WORK
./help lr4 base                # создать базу base
./help lr4 tasks 0 base 22     # контрольные задачи варианта 22 -> task0-01..03
./help lr4 dump1               # копия в текстовый файл;  ./help lr4 dump2 - в rar
./help lr4 dump3 8k            # многотомный rar с томами по 8 КБ
```
