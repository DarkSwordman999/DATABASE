# 🌐 lan_server — ЛР1: сервер PostgreSQL в локальной сети

Работа с базой [SALES](../DATA) по сети: сервер С (компьютер с PostgreSQL) и клиент К (другой компьютер с минимальным набором файлов psql). Задания вариантов — в [`tasks`](../tasks).

[← к общему описанию проекта](../README.md)

## Файлы

| Файл | Назначение |
|---|---|
| [`setup_lan.ps1`](setup_lan.ps1) | настройка сервера (от имени администратора): правило `pg_hba.conf` для сети (scram-sha-256), правило брандмауэра `PostgreSQL-inPort` (TCP 5432), перечитывание конфигурации |
| [`s_lan.bat`](s_lan.bat) | клиент К: выполнить сценарий в базе `sales` на сервере по сети (адрес — `LAN_HOST`, по умолчанию 192.168.0.102) |
| [`client_files.txt`](client_files.txt) | минимальный набор файлов клиента psql (каталог `D:\TO_PG\bin`) |
| [`check_server.sql`](check_server.sql) | проверка подключения: адрес и порт сервера, база, пользователь, адрес клиента, версия, число строк в таблицах |

## Запуск

```powershell
./help lr1 lan                                       # настроить сервер для сети (от администратора)
./help lr1 client 192.168.0.102 tasks/v20_task1.sql 01.01.2021 31.12.2022 мебель
./help lr1 client postgres@192.168.0.102:5432 tasks/v22_task1.sql 01.07.2019 30.06.2023 "ООО Турман"
```

### Защита ЛР1 в сети PMII

Сервер `192.168.1.50:5432`, база `sales`, пользователь `stud` (пароль — `$env:SRV_PASS` или `pgpass.conf`):

```powershell
./help srv check                                     # подключение и число строк в таблицах
./help srv all                                       # проверка и все 4 задания
./help srv v20 1                                     # задание варианта на сервере
./help srv stud@192.168.1.50:5432 v22 2 2018 2022 зима
./help srv 192.168.1.60 check                        # другой адрес: [пользователь@]хост[:порт]
```

Проверка доступности порта: `Test-NetConnection 192.168.1.50 -Port 5432`.
