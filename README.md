Лабораторные работы по дисциплине **«Программирование и администрирование баз данных»** (5 семестр) на учебной базе торговой организации **SALES**: PostgreSQL в локальной сети, объёмная БД и индексы, пользовательские типы, резервное копирование, функции на C, перенос в MS SQL Server, представления и функции T-SQL, программы на C# и Python с данными MS SQL Server.

Все работы выполнены для **двух вариантов — 20 и 22** — и проверены прогоном на реальных серверах (PostgreSQL 18.6, SQL Server 2019 LocalDB). У каждой папки есть свой `README.md` с подробным описанием её части проекта.

## 🚀 Быстрый старт

Нужны PostgreSQL 18 (`psql` в `PATH`); для ЛР4 — WinRAR, для ЛР5 — Visual Studio 2022, для ЛР6–ЛР8 — SQL Server (LocalDB или Express), для ЛР8 в.22 — Python с `pyodbc`.

Все работы запускаются одной командой: `./help` в PowerShell или cmd ([`help.cmd`](help.cmd) → [`helper/help.ps1`](helper/help.ps1), политику выполнения менять не нужно) или `./h` в Git Bash ([`h`](h)) — команды одинаковые.

```powershell
./help                     # все команды (./help example - с примерами запуска)
./help short               # блоки справки: lr1 … lr8, taxi, sql;  ./help short lr2 - один блок
./help db                  # создать базу sales и загрузить данные ЛР1
./help v20 1               # вариант 20, задание 1 с параметрами по умолчанию
./help v22 1 01.01.2020 31.12.2020 "ООО Турман"
./help lr2 def 20          # защита ЛР2;   ./help lr3 def 22 -3 4 - защита ЛР3
./help 17                  # аналог команды TAXI-db: топ-10 товаров по выручке
./help tree                # дерево файлов проекта (./help tree git - только файлы git)
```

Из `cmd` без скрипта — командные файлы: `s1.bat DATA\create_DB`, `s.bat DATA\create_tables`, `s.bat DATA\load_data`, `s.bat tasks\v20_task1.sql 21.08.2020 20.08.2023 мебель`.

- **Параметры проверяются до запуска**: число, формат (даты, годы, числа, `20|22`), период, значения из базы (категория, поставщик, коды); при ошибке команда не выполняется, выводятся причина и допустимые значения, код выхода — 1.
- **Видно, что выполняется**: в справке у каждой команды в `[...]` указан её файл, перед выполнением печатается `>>> Файл: …`.
- **Кириллица**: параметры передаются в psql через stdin (`\set`), поэтому не искажаются из-за CP1251 в командной строке Windows. Системный `tree /f` в PowerShell искажает русские имена файлов — для дерева проекта есть `./help tree`.

Подробно о сценарии — [`helper`](helper) и [руководство по сценарию](reports/docx/Руководство_по_сценарию_help.docx).

## ⚙️ Особенности окружения

- Служба PostgreSQL работает от `NETWORK SERVICE` и не читает файлы из профиля пользователя — DLL из ЛР5 копируются в `D:\PG_DLL`.
- База SALES в MS SQL Server создаётся с сортировкой `Cyrillic_General_CI_AS`, данные передаются в CP1251 (`BULK INSERT ... CODEPAGE = '1251'`).
- Для работы в локальной сети в `s*.bat` и `lab6/config.bat` достаточно заменить `localhost` / `(localdb)` на IP-адрес сервера; настройка сервера и защита ЛР1 в сети PMII — [`lan_server`](lan_server).
- Служебные сообщения psql приводятся к UTF-8: в `./help` — функцией `Fix-Line`, в `./h` — фильтром [`helper/fixenc.pl`](helper/fixenc.pl).
