# 💻 lab8 — ЛР8: данные MS SQL Server в программах

ЛР8 «Использование данных СУБД MS SQL Server в программах на универсальном языке программирования высокого уровня»: программа варианта читает базу SALES ([ЛР6](../lab6)) и выводит распределение величины по двум признакам за период. Период и значение признака 1 задаются параметрами командной строки.

[← к общему описанию проекта](../README.md)

## Варианты

| | Вариант 20 — C# ([`v20`](v20)) | Вариант 22 — Python ([`v22`](v22)) |
|---|---|---|
| Величина | количество проданных товаров, шт | затраты клиентов (`количество × цена2`) |
| Признак 1 / признак 2 | категория товара / квартал | поставщик / декада месяца |
| Период по умолчанию | 01.07.2019 – 30.06.2023 | 01.10.2021 – 31.01.2024 |
| Программа | [`v20/Lab08.cs`](v20/Lab08.cs) (.NET Framework 4, `System.Data.SqlClient`) | [`v22/lab08.py`](v22/lab08.py) (`pyodbc`, «ODBC Driver 17 for SQL Server») |
| Сборка / запуск | [`v20/cs.bat`](v20/cs.bat) → `Lab08.exe`, [`v20/run.bat`](v20/run.bat) | [`v22/run.bat`](v22/run.bat), зависимости — [`v22/requirements.txt`](v22/requirements.txt) |

Сервер по умолчанию — `(localdb)\MSSQLLocalDB` с Windows-аутентификацией; другой сервер задаётся переменной окружения `LAB8_SERVER` (в обоих вариантах). Собранный `Lab08.exe` в git не хранится.

## Запуск

```powershell
./help lr8 build                                  # компиляция программы C# (Lab08.cs)
./help lr8 20                                     # в.20: период по умолчанию, все категории
./help lr8 20 01.07.2019 30.06.2023 мебель
./help lr8 22                                     # в.22 (нужен pip install -r lab8/v22/requirements.txt)
./help lr8 22 01.10.2021 31.01.2024 "ООО Турман"
```

Категория и поставщик проверяются до запуска по данным в MS SQL Server ([`../lab6/check_db.sql`](../lab6/check_db.sql)). Результаты прогонов — [`../results/lr8_v20_results.txt`](../results/lr8_v20_results.txt), [`../results/lr8_v22_results.txt`](../results/lr8_v22_results.txt).
