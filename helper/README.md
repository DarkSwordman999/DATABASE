# 🧰 helper — сценарий запуска ./help и общие сценарии

Здесь лежит единая точка запуска всех работ — сценарий [`help.ps1`](help.ps1) (команда `./help` в PowerShell и cmd через [`../help.cmd`](../help.cmd); в Git Bash то же делает [`../h`](../h)), описание параметров команд, общие сценарии psql и аналоги команд TAXI-db для базы SALES (просмотр, JOIN, до/после, аналитика).

[← к общему описанию проекта](../README.md)

### Справка

```powershell
./help                     # все команды без примеров запуска;  ./help example - с примерами
./help short               # список блоков: lr1 … lr8, taxi, sql
./help short lr2           # один блок (то же: ./help short 2)
./help tree                # дерево файлов проекта (кириллица в UTF-8);  ./help tree git lab3
```

Параметры любой команды проверяются до запуска (число, формат, период, значения из базы); при ошибке выводятся причина, строка использования и допустимые значения, код выхода — 1. Перед выполнением печатается строка `>>> Файл: …` — какой сценарий запускается. Подробно — [руководство по сценарию](../reports/docx/Руководство_по_сценарию_help.docx).

## Аналоги команд TAXI-db (`./help <код>`)

По образцу [TAXI-db](https://github.com/DarkSwordman999/TAXI-db). Сценарии этой папки — коды 01–30 и 60–66; запросы с параметрами, представления, подзапросы и функции — в [`../queries`](../queries), контрольные вставки — в [`../control`](../control).

| Коды | Раздел | Примеры |
|---|---|---|
| 01–06, 16 | просмотр данных | `./help 01` товары, `./help 05` 10 последних продаж, `./help 16` структура таблиц (тип, NULL, ключ) |
| 07–12 | демонстрация JOIN | INNER, LEFT, RIGHT, FULL, CROSS, SELF JOIN |
| 60–66 | до/после UPDATE и DELETE | `./help 60` → `61` → `62`, `./help 63` → `64` → `65`, возврат — `./help 66` |
| 17–30 | аналитика | `./help 17` топ-10 товаров, `./help 19` выручка по месяцам, `./help 25` по дням недели, `./help 30` по поставщикам |

Деньги выводятся с двумя знаками после запятой, столбцы названы по-русски, без подчёркиваний. Команды 61, 64, 66 изменяют данные.
