# 🗃️ DATA — база SALES: схема, таблицы, исходные данные

Создание учебной базы торговой организации **SALES** в PostgreSQL (ЛР1). Все остальные работы используют эту базу: ЛР2 увеличивает таблицу `ПРОДАЖА` до 2 млн записей, ЛР4 копирует базу, ЛР6 переносит её в MS SQL Server.

[← к общему описанию проекта](../README.md)

## Схема

![Схема БД](DB_scheme.png)

| Таблица | Назначение |
|---|---|
| `РАЙОН`, `КАТЕГОРИЯ`, `ПОСТАВЩИК`, `ТОВАР`, `МАГАЗИН`, `СОТРУДНИК`, `КЛИЕНТ` | справочники |
| `РАБОТА` | смены сотрудников в магазинах (с какого по какой день, старший или рядовой) |
| `ПОСТАВКА` | поступление товаров (дата, товар, количество) |
| `ПРОДАЖА` | продажи (дата и время, магазин, товар, количество, клиент) |

Цены товара: `цена1` — закупочная (затраты на единицу), `цена2` — розничная (выручка за единицу), `хранение` — стоимость хранения единицы товара в день (ЛР7).

## Запуск

```powershell
./help db        # создать базу sales, таблицы и загрузить данные (create_DB, create_tables, load_data)
./help counts    # количество строк в таблицах
```

Из `cmd` без скрипта: `s1.bat DATA\create_DB`, затем `s.bat DATA\create_tables` и `s.bat DATA\load_data` (корень проекта).

После загрузки в `ПРОДАЖА` 1000 записей, в `ПОСТАВКА` — 352. Вернуть данные ЛР1 после ЛР2 — `./help lr2 restore`.
