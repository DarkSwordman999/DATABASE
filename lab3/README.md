# 🧮 lab3 — ЛР3: пользовательские типы данных

ЛР3 «Применение пользовательских типов данных»: составной тип, домен, ограничивающий значения полей встроенного типа, функции-методы и операторы, использование типа автономно и во временной таблице. Номер типа k = mod15(K−1)+1 по номеру варианта K. Файлы `def_*.sql` — защита ЛР3.

[← к общему описанию проекта](../README.md)

## Варианты

| | Вариант 20 (k = 5) | Вариант 22 (k = 7) |
|---|---|---|
| Тип / домен | `vector3_` / `vector3` — трёхмерный вектор `(x, y, z)` | `rational_` / `rational` — рациональное число `a/b` с целыми в `double` |
| Ограничения домена | координаты заданы и конечны | `a`, `b` целые, `\|a\|, \|b\| ≤ 2^53`, `b ≠ 0` |
| Операции | `+`, `−`, умножение на число, инверсия `−a`, модуль `@`, скалярное произведение `*`, проекция `->>`, проекция на ось и плоскость | конструкторы `rat(a, b)`, `rat(n)`, нормализация, `+ − * /`, умножение на целое, смена знака `−`, значение `float`, запись `'a/b'`, сравнение `== < >` |
| Сценарий | [`v20_vector3.sql`](v20_vector3.sql) | [`v22_rational.sql`](v22_rational.sql) |

[`cmplx.sql`](cmplx.sql) — пример преподавателя (комплексное число).

## Запуск

```powershell
./help lr3 cmplx     # пример преподавателя
./help lr3 20        # тип, домен, функции и операторы варианта 20
./help lr3 22        # то же для варианта 22
```

Для варианта 22 умножение `rat_mul` сокращает дроби крест-накрест, а НОД `rat_gcd` считается в `bigint`, поэтому арифметика точна при любых `a`, `b` домена.

## 🛡️ Защита ЛР3 (`def_*.sql`)

| | Вариант 20 | Вариант 22 |
|---|---|---|
| Задание | векторное произведение `W = a × b`; показать `W*a = 0` и `W*b = 0` | `x = a/b`, `−x = b/a` при `a ≠ 0` и `0/1` при `a = 0`; показать `(−x)*x` и `x*(−x)` = 1 или 0 |
| Реализация | функция `v3_cross`, оператор `#` (`*` для двух векторов — скалярное произведение) | функция `rat_inv`, оператор `~` (`−` у типа `rational` — смена знака) |
| Сценарий | [`def_v20_cross.sql`](def_v20_cross.sql) | [`def_v22_inverse.sql`](def_v22_inverse.sql) |
| Проверка | набор векторов (базисные, коллинеарные, нулевой, дробные), свойства `b × a = −(a × b)`, `\|a × b\| = \|a\|·\|b\|·sin φ`; 10 000 случайных пар | набор чисел, в т.ч. крайние значения домена; 10 000 случайных дробей — 0 ошибок |

```powershell
./help lr3 def 20                          # по умолчанию a = (1,2,3), b = (4,5,6)
./help lr3 def 20 "(1,0,0)" "(0,1,0)"      # свои векторы
./help lr3 def 22                          # по умолчанию x = 3/4
./help lr3 def 22 -3 4                     # свои a и b;   ./help lr3 def 22 0 7 - случай a = 0
```

Перед защитой команда без вывода пересоздаёт тип своего варианта. Для дробных координат `W*a` и `W*b` равны нулю с погрешностью вычислений в `double` (~1e-16), для целых — точно. Вывод — в отчёте ЛР3 (раздел «Задание на защиту») и [`../reports/out/lr3_def20.txt`](../reports/out/lr3_def20.txt), [`../reports/out/lr3_def22.txt`](../reports/out/lr3_def22.txt).
