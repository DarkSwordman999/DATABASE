# 🎯 tasks — ЛР1: индивидуальные задания вариантов 20 и 22

Запросы ЛР1 «Сервер баз данных PostgreSQL в локальной сети Windows» к базе [SALES](../DATA). Каждое задание — распределение величины по двум признакам за период; период и значение признака 1 задаются параметрами.

[← к общему описанию проекта](../README.md)

## Задания

| Файл | Вариант | Величина | Признак 1 / признак 2 | Период по умолчанию |
|---|---|---|---|---|
| [`v20_task1.sql`](v20_task1.sql) | 20, задание 1 | объём поставок, ден. ед. (`количество × цена1`) | категория товара / квартал | 21.08.2020 – 20.08.2023 |
| [`v20_task2.sql`](v20_task2.sql) | 20, задание 2 | количество проданных товаров, шт | день недели / район поставщика | 2019 – 2023 |
| [`v22_task1.sql`](v22_task1.sql) | 22, задание 1 | выручка, ден. ед. (`количество × цена2`) | поставщик / декада месяца | 01.07.2019 – 30.06.2023 |
| [`v22_task2.sql`](v22_task2.sql) | 22, задание 2 | затраты клиентов, ден. ед. | время года / пол клиента | 2018 – 2022 |

Параметры передаются в сценарий как `arg1`, `arg2`, `arg3`: начало и конец периода (даты `ДД.ММ.ГГГГ` или годы) и значение признака 1 (без него — все значения). Общая обработка параметров — [`../helper/params_dates.sql`](../helper/params_dates.sql), [`../helper/params_years.sql`](../helper/params_years.sql).

## Запуск

```powershell
./help v20 1                                          # в.20, задание 1, параметры по умолчанию
./help v20 1 01.01.2021 31.12.2022 мебель             # период и категория
./help v20 2 2019 2023 пт                             # годы и день недели
./help v22 1 01.01.2020 31.12.2020 "ООО Турман"       # в.22, задание 1: период и поставщик
./help v22 2 2018 2022 зима                           # годы и время года
./help all                                            # все 4 задания
```

Из `cmd`: `s.bat tasks\v20_task1.sql 21.08.2020 20.08.2023 мебель`.

Параметры проверяются до запуска: реальная дата, начало не позже конца, категория и поставщик — из базы, день недели `пн`…`вс`, время года `зима|весна|лето|осень`.

Те же задания выполняются на сервере в сети ([`lan_server`](../lan_server): `./help srv v20 1 …`), после резервного копирования ([ЛР4](../lab4)) и в MS SQL Server на T-SQL ([ЛР6](../lab6/tasks)).
