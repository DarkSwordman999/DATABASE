# 📐 lab7 — ЛР7: представления и функции пользователя в MS SQL Server

ЛР7 «Представления и функции пользователя в MS SQL Server» на базе SALES, перенесённой в [ЛР6](../lab6): две расчётные задачи — месячная премия сотрудников и затраты на хранение товаров.

[← к общему описанию проекта](../README.md)

## Файлы

| Файл | Назначение |
|---|---|
| [`create_objects.sql`](create_objects.sql) | создание объектов: задача 1 — `v_выручка_день`, `f_месяц`, `f_вес_смены`, `f_премия`; задача 2 — `v_движение_товара`, `f_дни`, `f_хранение` |
| [`calculate1.sql`](calculate1.sql) | задача 1: премия сотрудников за период [D1, D2]; P — % выручки на премию, M — на сколько % старший менеджер получает больше рядового, N — имя сотрудника (необязательно) |
| [`calculate2.sql`](calculate2.sql) | задача 2: затраты на хранение за период [D1, D2]; alpha (0..1) — доля суток хранения в день продажи (формула (11)), G — товар (необязательно) |
| [`s.bat`](s.bat) | запуск сценария T-SQL с параметрами |

## Запуск

```powershell
./help lr7 create                                   # создать представления и функции
./help lr7 1 01.01.2021 30.06.2021 8.5 10.5         # премия всех сотрудников
./help lr7 1 01.07.2022 31.12.2022 7.5 12 Ольга     # премия одного сотрудника
./help lr7 2 01.01.2021 30.06.2021 0.5              # затраты на хранение всех товаров
./help lr7 2 01.07.2022 31.12.2022 0.5 шкаф         # одного товара
```

## Результаты

| Проверка | Результат |
|---|---|
| премия за весь период, P = 10 %, M = 10 % | **59 206.10** — совпадает с эталоном из примера преподавателя (`bonus3`) |
| `calculate1 01.01.2021 30.06.2021 8.5 10.5` | 4 135.67 (Андрей — 714.34) |
| `calculate2 01.01.2021 30.06.2021 0.5 плащ` | 1 051.10 — совпадает с независимым расчётом в PostgreSQL |

Остатки товаров по формуле (11) нигде не становятся отрицательными, т.е. данные удовлетворяют условию (5) модели. Прогоны с параметрами каждого варианта — [`../results/lr7_v20_results.txt`](../results/lr7_v20_results.txt), [`../results/lr7_v22_results.txt`](../results/lr7_v22_results.txt).
