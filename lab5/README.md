# ⚙️ lab5 — ЛР5: функции пользователя на C для PostgreSQL

ЛР5 «Разработка функций пользователя на C для PostgreSQL»: две функции варианта на C (каждая в своём файле) собираются компилятором MSVC в библиотеку `vNN.dll`, регистрируются в PostgreSQL как `STRICT`-функции и проверяются на таблице T.

[← к общему описанию проекта](../README.md)

## Варианты

| | Вариант 20 | Вариант 22 |
|---|---|---|
| f1 | `v20_floor(x double) → int` — наибольшее целое, не превосходящее x ([`v20_f1.c`](v20_f1.c)) | `v22_cosd(x double) → double` — косинус угла в градусах, для углов, кратных 60° и 90°, — точные значения ([`v22_f1.c`](v22_f1.c)) |
| f2 | `v20_alltrim(s varchar) → varchar` — удаление пробелов и табуляций в начале и в конце строки ([`v20_f2.c`](v20_f2.c)) | `v22_pos(s, s1 varchar) → int` — номер символа, с которого `s1` входит в `s` (0 — не входит), в символах, а не в байтах ([`v22_f2.c`](v22_f2.c)) |
| Демонстрация | [`v20_test.sql`](v20_test.sql) | [`v22_test.sql`](v22_test.sql) |

## Файлы сборки

| Файл | Назначение |
|---|---|
| [`build.bat`](build.bat) | полная сборка варианта: `c1.bat` для обоих `.c` → `dll.bat` → `show1.bat` и копирование `vNN.dll` в каталог, доступный серверу (по умолчанию `D:\PG_DLL`) |
| [`c1.bat`](c1.bat), [`dll.bat`](dll.bat), [`show1.bat`](show1.bat) | компиляция одного файла, сборка библиотеки, список экспортируемых функций |

Продукты сборки (`lab5/build`) в git не хранятся.

## Запуск

```powershell
./help lr5 build 20            # собрать v20.dll в D:\PG_DLL;   ./help lr5 build 22 D:\PG_DLL
./help lr5 20                  # зарегистрировать функции и показать их работу;   ./help lr5 22 D:/PG_DLL
```

Нужна Visual Studio 2022 (MSVC). Служба PostgreSQL работает от `NETWORK SERVICE` и не читает файлы из профиля пользователя, поэтому библиотека копируется вне `C:\Users` (права: `icacls D:\PG_DLL /grant "*S-1-5-20:(OI)(CI)RX"`).

## Результаты

Обе библиотеки собираются из двух независимых `.c`-файлов; результаты функций на таблице T совпадают со встроенными `floor`, `btrim`, `cosd`, `position`. STRICT-функции возвращают NULL для NULL-аргументов без вызова кода на C. Вывод сборки и демонстрации — [`../reports/out/lr5_*.txt`](../reports/out).
